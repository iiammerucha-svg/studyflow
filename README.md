# StudyFlow 🌸  เวอร์ชัน 1.0.1

แอปจัดการการบ้านและกำหนดส่ง (ภาษาไทย) ติดตั้งลงหน้าจอโฮมได้ ใช้ออฟไลน์ได้ ข้อมูลเก็บในเครื่องของผู้ใช้เท่านั้น

## ไฟล์ในชุดนี้ (วางไว้ชั้นนอกสุด ไม่ต้องสร้างโฟลเดอร์)
`index.html` (ตัวแอป) · `sw.js` (ออฟไลน์ + รับแจ้งเตือน) · `manifest.webmanifest` (ข้อมูลติดตั้ง) · `icon-*.png` และ `apple-touch-icon.png` (ไอคอน) · `Sarabun-*.ttf` (ฟอนต์ไทย)

## ขึ้น GitHub Pages
1. สร้าง repository ชื่อ `studyflow` (Public) แล้วกด **uploading an existing file**
2. เลือกไฟล์ทั้งหมดในชุดนี้ (ไม่ใช่ไฟล์ zip) → **Commit changes**
3. **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main** / **(root)** → **Save**
4. รอ 1-3 นาที ลิงก์แอป: `https://ชื่อผู้ใช้.github.io/studyflow/`
5. iPhone: เปิดด้วย Safari → ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม** / Android: Chrome → ⋮ → **ติดตั้งแอป**

## เตือนตอนปิดแอป
ต้องมีตัวส่งแจ้งเตือนของตัวเอง (Cloudflare Worker ฟรี) ทำตามไฟล์ `push-guide-th.md` ที่แยกให้ แล้ววางลิงก์ในแอปที่ ตั้งค่า → เตือนตอนปิดแอป

## อัปเดตแอป
1. อัปโหลดไฟล์ใหม่ทับของเดิม (ปกติคือ `index.html` กับ `sw.js`) → **Commit changes**
2. รอ 1 นาที แล้วปิดแอปให้สนิทบนมือถือ เปิดใหม่ 2 ครั้ง
ข้อมูลงานไม่หาย เพราะเก็บในเครื่อง
